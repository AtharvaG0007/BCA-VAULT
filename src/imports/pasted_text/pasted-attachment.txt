6. Vault Credit System (Core Feature)
Philosophy
Credits are BCA Vault's in-app loyalty currency. They reduce the effective price of every purchase,
drive repeat engagement, and reward referrals — creating a viral growth loop.

Earning Credits
Event	Credits Earned
Account signup	+50
Email verification	+20
First purchase	+30
Successful referral (after friend's first purchase)	+100
Leave a review/rating	+10
7-day login streak	+25
Newsletter subscribe	+15
Birthday bonus	+50
Monthly top-buyer (admin grant)	+200

Spending Credits
•	1 Credit = ₹1 discount at checkout
•	Maximum credit usage: 30% of order value (prevents full-free abuse)
•	Credits applied automatically at checkout (can be toggled off by user)
•	Credit top-up packs: 100 credits (₹90) / 250 credits (₹210) / 500 credits (₹400)
•	Credits expire after 180 days of inactivity (rolling expiry, not fixed date)

Credit Optimization Engine
Build a CreditOptimizer utility at /lib/credits/optimizer.ts that:
•	Calculates max applicable credits for any cart
•	Stacks credits with coupon codes (coupon applies first, credits on remainder)
•	Surfaces "you'll save ₹X more if you use credits" nudge in cart
•	Recommends earning actions if balance is low (e.g. "Leave a review to earn 10 credits")
•	Shows expiry warnings 7 days before credits expire (toast + email)

Credit Anti-Abuse Rules (Cloud Functions enforced)
•	Credits only mutated server-side via Cloud Functions — never via client Firestore SDK
•	Referral credits granted only after referred user completes a paid purchase (not just signup)
•	Max 5 credit-earning events per user per hour (velocity cap)
•	Referral self-abuse detection: flag same device/IP referrals
•	Admin manual override with full audit log at /admin/credits

8. Firebase Security Rules
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function isAuth() { return request.auth != null; }
    function isOwner(uid) { return request.auth.uid == uid; }
    function isAdmin() {
      return isAuth() && get(/databases/.../users/$(request.auth.uid))
        .data.role in ['admin','superadmin'];
    }

    // Users: credits field is server-only (never writable from client)
    match /users/{uid} {
      allow read: if isOwner(uid) || isAdmin();
      allow create: if isOwner(uid);
      allow update: if isOwner(uid)
        && !('credits' in request.resource.data.diff(resource.data).affectedKeys())
        && !('role' in request.resource.data.diff(resource.data).affectedKeys());
    }

    // Credit transactions: Cloud Functions only
    match /credit_transactions/{txnId} {
      allow read: if isAuth() && resource.data.uid == request.auth.uid;
      allow write: if false;
    }

    // Products: public read if published, admin write
    match /products/{productId} {
      allow read: if resource.data.isPublished == true;
      allow write: if isAdmin();
    }

    // Orders: own read, Cloud Function write only
    match /orders/{orderId} {
      allow read: if isAuth() && resource.data.uid == request.auth.uid;
      allow write: if false;
    }

    // Reviews: read all, create own (no update/delete)
    match /reviews/{reviewId} {
      allow read: if true;
      allow create: if isAuth() && request.resource.data.uid == request.auth.uid;
      allow update, delete: if false;
    }
  }
}
