React 18.3.1, TypeScript, Vite 6.3.5, React Router 7, Tailwind 4, Radix UI, Motion, Supabase JS, PDF.js and pdf-lib implement a single-page application. Student Auth persists sessions; admin Auth uses separate memory-only sessions. Route guards wrap student/admin dashboards. ## Additional confirmed finding

**High — Exam Kits validation is still broken on inspected remote main.** The remote component uses a quoted JSX pattern containing doubled backslashes: `pattern="\\+?[0-9\\s\\-]{10,18}"`. JSX quoted attributes retain those backslashes; JavaScript strings inside braces have different escaping semantics. Compiling that exact attribute with the browser-equivalent `v` flag throws `Invalid character in character class`. The previous fix is therefore insufficient. The local checkout has no ExamKitsPage; this remote-only file was not copied over unrelated local work. Repair on synchronized main and test digit counts as well as allowed characters; a punctuation-only value must not pass.
